# Privacy Policy

LLM Chat Bridge has one purpose: helping users transfer the currently open LLM conversation to another supported LLM website.

## Data handled

The extension reads visible chat content only on supported LLM websites when the user clicks **Capture current chat**. This may include prompts, responses, visible links, code blocks, tables, citations, file names, and image descriptions/placeholders.

## Local processing

Chat content is processed locally in the browser. LLM Chat Bridge does not operate a backend, does not sell data, does not use chat content for advertising, and does not transmit chat content to the extension developer.

## Sharing

Chat content is shared only when the user chooses to copy it to the clipboard or fill it into another LLM website. The destination LLM provider may process that content according to its own terms and privacy policy.

## Storage

The extension stores settings such as enabled providers and may store small recent-transfer metadata, such as source provider and timestamp. It does not store full chat transcripts by default.

## Permissions

The extension requests access only to supported LLM domains needed for its transfer feature. It uses clipboard access only for the explicit copy/fallback flow.
